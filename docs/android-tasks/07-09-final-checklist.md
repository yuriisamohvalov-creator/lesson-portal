# Этап 7.9: Финальный чек-лист перед Production

## Цель этапа

Выполнить финальную проверку всех компонентов приложения перед выпуском в Production (Google Play Public Release).

---

## Часть 1: Тестирование

### Unit-тесты

- [ ] Все unit-тесты проходят (100% passing)
- [ ] Покрытие тестами критического функционала > 80%
- [ ] Нет пропуска тестов (@Ignore) без документации
- [ ] Тесты запускаются через CI автоматически

**Команда для проверки:**
```bash
cd android
./gradlew testDebugUnitTest
```

### UI-тесты (Instrumented Tests)

- [ ] Все UI-тесты проходят на эмуляторе API 34
- [ ] Тесты запущены минимум на одном реальном устройстве
- [ ] Отчёт о тестах сохранён
- [ ] Нет flaky тестов (нестабильных)

**Команда для проверки:**
```bash
./gradlew connectedAndroidTest
```

### Smoke-тесты

- [ ] Android 8.0 (API 26) — все функции работают
- [ ] Android 10 (API 29) — все функции работают
- [ ] Android 12 (API 31) — все функции работают
- [ ] Android 14 (API 34) — все функции работают
- [ ] Матрица тестирования заполнена

### Тесты на реальном устройстве

- [ ] Производительность оценена (время запуска < 3с)
- [ ] Потребление памяти в норме (< 200 MB)
- [ ] LeakCanary не показал утечек
- [ ] Камера работает (если используется)
- [ ] Фоновый режим корректен

## Часть 2: Функциональность

### Авторизация и сессия

- [ ] Вход с правильными данными работает
- [ ] Вход с неправильными данными показывает ошибку
- [ ] Сессия сохраняется после перезапуска
- [ ] Refresh токена работает автоматически
- [ ] Logout очищает сессию
- [ ] 401 ошибка → редирект на логин

### Статьи

- [ ] Список статей загружается
- [ ] Pull-to-refresh обновляет список
- [ ] Skeleton отображается при загрузке
- [ ] Empty state показывается при пустом списке
- [ ] Статья открывается с контентом
- [ ] Комментарии загружаются и добавляются
- [ ] Создание статьи работает
- [ ] Редактирование статьи работает
- [ ] Валидация полей показывает ошибки

### Курсы

- [ ] Список курсов загружается
- [ ] Фильтрация/сортировка работает
- [ ] Детали курса отображаются
- [ ] Прогресс курса виден

### Профиль

- [ ] Данные пользователя загружаются
- [ ] Редактирование профиля работает
- [ ] Аватар загружается/обновляется
- [ ] Статистика отображается

### Темы и UI

- [ ] Светлая тема работает корректно
- [ ] Тёмная тема работает корректно
- [ ] Переключение темы не ломает UI
- [ ] Типографика читаема на всех экранах
- [ ] Отступы (Dimens) консистентны

### Офлайн-режим

- [ ] Offline-banner появляется при потере сети
- [ ] Кэшированные данные отображаются
- [ ] Banner исчезает при восстановлении связи
- [ ] Данные обновляются автоматически

### Обработка ошибок

- [ ] Network error → понятное сообщение
- [ ] 401 ошибка → редирект на логин
- [ ] 403 ошибка → сообщение о правах
- [ ] 500 ошибка → сообщение об ошибке сервера
- [ ] Таймауты обрабатываются корректно

## Часть 3: Производительность

### Время запуска

- [ ] Холодный старт < 3 секунд
- [ ] Горячий старт < 1 секунды
- [ ] Splash screen отображается корректно

**Проверка:**
```bash
adb shell am start -W ru.samoh.lessonsportal/.ui.MainActivity
# ThisTime должно быть < 3000ms
```

### Память

- [ ] Пиковое потребление < 200 MB
- [ ] Нет утечек памяти (LeakCanary чист)
- [ ] Приложение не убивается системой в фоне

**Проверка:**
```bash
adb shell dumpsys meminfo ru.samoh.lessonsportal
```

### Скролл и анимации

- [ ] Скролл списков плавный (60 FPS)
- [ ] Нет рывков при загрузке изображений
- [ ] Анимации переходов плавные
- [ ] Нет просадок FPS при скролле

**Проверка:**
```bash
adb shell dumpsys SurfaceFlinger --latency ru.samoh.lessonsportal
```

### Размер приложения

- [ ] Debug APK < 20 MB
- [ ] Release AAB < 10 MB
- [ ] R8/shrinking включены
- [ ] Ресурсы оптимизированы

**Проверка:**
```bash
ls -lh app/build/outputs/bundle/release/app-release.aab
# Ожидаемый размер: ~4-6 MB
```

## Часть 4: Безопасность

### Токены и данные

- [ ] Токены не логируются в Logcat
- [ ] Пароли не сохраняются в plain text
- [ ] Чувствительные данные шифруются
- [ ] Network Security Config настроен

### Разрешения

- [ ] Запрошены только необходимые разрешения
- [ ] Разрешения запрошены в runtime (для опасных)
- [ ] Объяснение зачем нужно разрешение

### ProGuard/R8

- [ ] Obfuscation включён для release
- [ ] ProGuard правила настроены
- [ ] Mapping файлы сохраняются

**Проверка в build.gradle.kts:**
```kotlin
buildTypes {
    release {
        isMinifyEnabled = true
        isShrinkResources = true
        proguardFiles(...)
    }
}
```

### Подпись

- [ ] Release keystore создан
- [ ] Keystore сохранён в надёжном месте
- [ ] Secrets добавлены в GitHub
- [ ] CI собирает подписанный AAB
- [ ] Подпись проверена через apksigner

## Финальная проверка перед релизом

### Команды для быстрой проверки

```bash
cd android

# 1. Очистка и полная сборка
./gradlew clean

# 2. Запуск всех unit-тестов
./gradlew testDebugUnitTest

# 3. Проверка линта
./gradlew lint

# 4. Проверка форматирования
./gradlew ktlintCheck

# 5. Сборка release AAB
./gradlew bundleRelease

# 6. Проверка размера
ls -lh app/build/outputs/bundle/release/app-release.aab

# 7. Проверка подписи
$ANDROID_HOME/build-tools/34.0.0/apksigner verify \
  --print-certs app/build/outputs/bundle/release/app-release.aab

# 8. Git проверка
git status
git diff --check
```

### Чек-лист "Готов к релизу"

Перед нажатием кнопки **Publish** в Google Play:

- [ ] Все unit-тесты прошли ✅
- [ ] Все UI-тесты прошли ✅
- [ ] Smoke-тесты на 4 версиях Android пройдены ✅
- [ ] Тесты на реальном устройстве пройдены ✅
- [ ] Критических багов нет ✅
- [ ] Pre-launch report чист ✅
- [ ] Документация обновлена ✅
- [ ] Version code увеличен ✅
- [ ] Changelog обновлён ✅
- [ ] Команда уведомлена о релизе ✅

## План релиза

### День релиза

1. **Утро:**
   - [ ] Финальная проверка чек-листа
   - [ ] Создание тега версии
   - [ ] Push тега в репозиторий
   - [ ] Ожидание завершения CI сборки

2. **День:**
   - [ ] Скачивание signed AAB из артефактов
   - [ ] Локальная проверка подписи
   - [ ] Загрузка в Google Play Internal Testing
   - [ ] Быстрая проверка внутренними тестировщиками

3. **Вечер:**
   - [ ] Получение feedback от тестировщиков
   - [ ] При отсутствии критических проблем — публикация в Production
   - [ ] Мониторинг Pre-Launch Report

### После релиза (1-7 дней)

- [ ] Мониторинг крашей (Google Play Console → Android Vitals)
- [ ] Чтение отзывов пользователей
- [ ] Ответы на отзывы
- [ ] Сбор метрик (установки, DAU, retention)
- [ ] Планирование хотфиксов (если нужны)

### Метрики успеха

| Метрика | Цель |
|---------|------|
| Установки (первая неделя) | > 100 |
| Рейтинг | > 4.0 звёзд |
| Краши | < 1% сессий |
| ANR | < 0.5% сессий |

## Rollback план

Если после релиза обнаружена критическая проблема:

### Немедленные действия

1. **Оценить масштаб:**
   - Сколько пользователей затронуто?
   - Насколько серьёзна проблема?
   - Можно ли исправить быстро?

2. **Варианты:**

   **A. Хотфикс (рекомендуется):**
   - Исправить проблему
   - Срочно собрать новую версию
   - Загрузить как обновление

   **B. Откат релиза:**
   - В Google Play Console остановить распространение
   - Пользователи не получат обновление
   - Уже установившие — останутся на проблемной версии

3. **Коммуникация:**
   - Уведомить пользователей через Release Notes
   - Ответить на негативные отзывы
   - Обновить статус в команде

### Процедура хотфикса

```bash
# 1. Создать ветку hotfix
git checkout -b hotfix/critical-bug-fix

# 2. Исправить проблему
# ... edit files ...

# 3. Закоммитить
git add .
git commit -m "fix: critical bug fix description"

# 4. Протестировать срочно
./gradlew testDebugUnitTest

# 5. Создать тег
git tag v1.0.1-hotfix
git push origin hotfix/critical-bug-fix
git push origin v1.0.1-hotfix

# 6. Дождаться CI сборки
# 7. Загрузить в Google Play
```
