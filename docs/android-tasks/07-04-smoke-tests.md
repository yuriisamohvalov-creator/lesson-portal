# Этап 7.4: Smoke-тесты на разных версиях Android

## Цель этапа

Провести ручное smoke-тестирование приложения на четырёх версиях Android для выявления критических проблем совместимости.

## Необходимые эмуляторы

| Версия | API Level | Статус | Приоритет |
|--------|-----------|--------|-----------|
| Android 8.0 (Oreo) | 26 | Минимальная поддерживаемая | Критический |
| Android 10 (Q) | 29 | Популярная версия | Высокий |
| Android 12 (S) | 31 | Средняя версия | Высокий |
| Android 14 (Upside Down Cake) | 34 | Последняя стабильная | Основной |

---

## Подготовка к smoke-тестированию

### Шаг 1: Запуск всех эмуляторов

```bash
# Запустить все 4 эмулятора
emulator -avd Pixel_6_API_26 -no-boot-anim &
emulator -avd Pixel_6_API_29 -no-boot-anim &
emulator -avd Pixel_6_API_31 -no-boot-anim &
emulator -avd Pixel_6_API_34 -no-boot-anim &

# Дождаться загрузки (около 2-3 минут)
sleep 120

# Проверить подключение всех устройств
adb devices
```

**Ожидаемый вывод:**
```
List of devices attached
emulator-5554    device
emulator-5556    device
emulator-5558    device
emulator-5560    device
```

### Шаг 2: Установка приложения на все эмуляторы

```bash
cd android

# Сборка debug APK
./gradlew assembleDebug

# Установка на все устройства
adb devices | grep "device$" | cut -f1 | while read device; do
  echo "📱 Установка на устройство $device"
  adb -s $device install -r app/build/outputs/apk/debug/app-debug.apk
done
```

### Шаг 3: Подготовка тестовых данных

**Тестовые учётные записи:**
- Email: `test@example.com` / Пароль: `TestPass123!`
- Email: `user@example.com` / Пароль: `UserPass456!`

**Подготовить сценарии:**
- Список статей (минимум 5 статей)
- Список курсов (минимум 3 курса)
- Заполненный профиль пользователя
- Несколько комментариев к статьям

## Автоматизация smoke-тестов (опционально)

### Скрипт для последовательного тестирования

```bash
#!/bin/bash
# scripts/smoke-tests-manual-helper.sh

echo "🚀 Smoke Test Helper Script"
echo ""

EMULATORS=("Pixel_6_API_26" "Pixel_6_API_29" "Pixel_6_API_31" "Pixel_6_API_34")
APK_PATH="android/app/build/outputs/apk/debug/app-debug.apk"

for i in "${!EMULATORS[@]}"; do
  emulator_name="${EMULATORS[$i]}"
  api_version=$((26 + i * 3))
  if [ $i -eq 3 ]; then
    api_version=34
  fi

  echo "═══════════════════════════════════════"
  echo "📱 Эмулятор #$((i+1)): $emulator_name (API $api_version)"
  echo "═══════════════════════════════════════"
  echo ""
  echo "Команды для работы с этим эмулятором:"
  echo ""
  echo "1. Запуск эмулятора:"
  echo "   emulator -avd $emulator_name -no-boot-anim &"
  echo ""
  echo "2. Установка приложения:"
  echo "   adb -s emulator-$((5554 + i * 2)) install -r $APK_PATH"
  echo ""
  echo "3. Запуск приложения:"
  echo "   adb -s emulator-$((5554 + i * 2)) shell am start -n ru.samoh.lessonsportal/.ui.MainActivity"
  echo ""
  echo "4. Просмотр логов:"
  echo "   adb -s emulator-$((5554 + i * 2)) logcat | grep -i 'lessonsportal'"
  echo ""
  echo "5. Отключить сеть (для теста офлайн):"
  echo "   adb -s emulator-$((5554 + i * 2)) shell svc wifi disable"
  echo ""
  echo "6. Сделать скриншот:"
  echo "   adb -s emulator-$((5554 + i * 2)) shell screencap -p /sdcard/screenshot.png"
  echo "   adb -s emulator-$((5554 + i * 2)) pull /sdcard/screenshot.png smoke-api$api_version.png"
  echo ""
  echo ""
done

echo "═══════════════════════════════════════"
echo "✅ Помощник подготовил команды для всех эмуляторов"
echo "═══════════════════════════════════════"
```

**Использование:**
```bash
chmod +x scripts/smoke-tests-manual-helper.sh
./scripts/smoke-tests-manual-helper.sh
```

## Возможные проблемы и решения

### Проблема: Краш на старой версии Android (API 26)

**Возможные причины:**
- Использование API, недоступных в старых версиях
- Проблемы с совместимостью библиотек

**Решение:**
1. Изучить логи краша:
   ```bash
   adb logcat | grep -A 20 "FATAL"
   ```
2. Проверить minSdkVersion в build.gradle
3. Добавить проверки версии перед использованием новых API
4. Использовать AndroidX и Jetpack библиотеки

### Проблема: UI выглядит differently на разных версиях

**Возможные причины:**
- Различия в системных темах
- Разные шрифты по умолчанию
- Изменения в Material Design

**Решение:**
1. Использовать Material3 Components
2. Явно задавать тему приложения
3. Тестировать на всех целевых версиях
4. Документировать ожидаемые различия

### Проблема: Медленная работа на старых устройствах

**Возможные причины:**
- Ограниченные ресурсы эмулятора
- Тяжёлые операции в UI потоке

**Решение:**
1. Увеличить RAM эмулятора до 4GB
2. Использовать snapshot для быстрого запуска
3. Оптимизировать тяжёлые операции
4. Добавить pagination для больших списков
